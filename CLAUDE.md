# Carte des régiments

Projet d'Adeh : carte interactive des implantations de l'Armée de terre (site GitHub Pages + appli installable).

Avant tout travail, lire les documents de suivi dans cet ordre :
1. `docs/claude/METHODE.md`
2. `docs/claude/REFERENCE.md`
3. `docs/claude/IDEES_EN_ATTENTE.md`
4. `docs/claude/PROCHAINE_SESSION.md` (toujours en dernier)

Règles clés : éditer `src/carte.template.html` (jamais `index.html`), fabriquer avec `python3 src/build.py`,
source de données sûre = sengager.fr. Ne jamais toucher au dépôt `ember-guard`.
